WHOOP · Garmin · FreeStyle Libre · Claude via your API key · Ollama optional

One file. One writer.

Everything lives in a single SQLite database on your disk. Copy it, back it up, open it with any SQLite tool. A small daemon on 127.0.0.11 is the only process that writes to it. Connector tokens and API keys are stored encrypted with AES-256-GCM.2

Your record outlives the subscription and the sensor.

  1. Nobody else holds a copy.

    One SQLite file on your disk, and no account. The only Homeostat server is the public demo, and it holds synthetic data.

  2. Nobody else reads your vault.

    Questions go to Claude with only the records they need, on your own API key. Or to Ollama, and nothing leaves at all. Health values and prompts are never written to logs.

  3. Nobody can lock you out.

    Export everything as FHIR R4. Source release coming, under the MIT license.

  4. Nobody gets telemetry.

    The app has no analytics, and its map tiles live on your disk. This page loads nothing from third parties either.3

Every number has a receipt.

Click any value to see where it came from: connector, batch, raw payload hash, revision.4 Ask cites the same chain.

An AI that has to show its work.

Ask in plain language. Each number in the answer cites the measurement it came from. A number that doesn't trace back is flagged not in evidence, inside the answer. Answers describe your data and give no medical or dosing advice.

Questions

Is it a medical device?
No. Homeostat shows your own data and cites where each number came from. It doesn't diagnose anything, and Ask gives no medical or dosing advice.
Does my data leave my computer?
Your data stays in one file on your computer. When you ask Claude a question, only that question and the records it needs go to Anthropic, under your own API key. With Ollama, nothing leaves.
Which devices does it support?
WHOOP, Garmin and FreeStyle Libre.
Can I try it?
Yes. The live demo is the real app on synthetic sample data. It's read-only and needs no sign-up. You can ask it questions, and Claude answers them on the demo's own key, up to a daily limit.
When can I install it?
There is no date yet. Homeostat runs from source today and has no installer, but you can try the live demo now. Email hello@gethomeostat.com and you'll get one email when it installs.

I wear a WHOOP, a Garmin watch and a FreeStyle Libre. Each came with its own app, and each app kept one slice of me. I got tired of switching between three of them to answer one question.

The connectors, the evidence drawer, Ask with citations, offline run maps, Training, Goals, the MCP server and FHIR export all work. What's missing is an installer.
